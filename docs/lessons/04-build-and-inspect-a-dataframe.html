M04C01 · Explore · predict · practice

Make a table from a dictionary

A DataFrame is a two-dimensional table with rows and named columns. Pass a dictionary of equally long lists to pd.DataFrame(). Each dictionary key becomes a column name. Each list position supplies the values for one row.

Read the example

data = {"Name": ["Amira", "Bilal", "Chloe"], "Age": [20, 21, 19]}
df = pd.DataFrame(data)
print(df)
print(type(df).__name__)
print("Rows and columns:", df.shape)
Verified example output · pandas 2.2.3
    Name  Age
0  Amira   20
1  Bilal   21
2  Chloe   19
DataFrame
Rows and columns: (3, 2)

Watch for this. Call pd.DataFrame(...) with a capital D and F; Python names are case-sensitive.

Your turn

Add a Campus list with RAK, Dubai, and RAK to data before building df. Print the new table and shape.

For the code check, keep these result variable names: df. Different valid approaches are welcome.

Show a hint

Add another key with a list of exactly three values.

Show one worked solution
data = {
    "Name": ["Amira", "Bilal", "Chloe"],
    "Age": [20, 21, 19],
    "Campus": ["RAK", "Dubai", "RAK"]
}
df = pd.DataFrame(data)
print(df)
print("Rows and columns:", df.shape)

The shape becomes (3, 3). The number of rows stays the same while the new key adds one data column.

  2. Predict. (3, 2): three rows and two columns.
  3. Explain. No. The index labels the rows and is separate from the two named data columns.

M04C02 · Explore · predict · practice

Build a table from records

A list of dictionaries can also become a DataFrame. Each dictionary contributes a row, and pandas matches fields by their keys. If one record lacks a field, pandas marks that cell as missing. The table therefore does not require every record to contain the same keys.

Read the example

rows = [
    {"Name": "Amira", "Age": 20, "Campus": "RAK"},
    {"Name": "Bilal", "Age": 21},
    {"Name": "Chloe", "Age": 19, "Campus": "RAK"}
]
df = pd.DataFrame(rows)
print(df)
print("Missing campus:", df["Campus"].isna().sum())
Verified example output · pandas 2.2.3
    Name  Age Campus
0  Amira   20    RAK
1  Bilal   21    NaN
2  Chloe   19    RAK
Missing campus: 1

Watch for this. Missing-value display can vary with dtype and pandas version; inspect it with isna().

Your turn

Add Campus as Dubai to Bilal's record before constructing df. Check that no campus values are missing.

For the code check, keep these result variable names: df. Different valid approaches are welcome.

Show a hint

Update rows[1]["Campus"] before calling pd.DataFrame(rows).

Show one worked solution
rows = [
    {"Name": "Amira", "Age": 20, "Campus": "RAK"},
    {"Name": "Bilal", "Age": 21},
    {"Name": "Chloe", "Age": 19, "Campus": "RAK"}
]
rows[1]["Campus"] = "Dubai"
df = pd.DataFrame(rows)
print(df)
print("Missing campus:", df["Campus"].isna().sum())

Bilal now has Dubai in the Campus column. There are zero missing Campus values.

Compare your explanations
  1. Read. The second record, for Bilal.
  2. Predict. No. Bilal stays in the table with a missing Campus value.
  3. Explain. Record dictionaries name their fields, so pandas can identify the missing field for a particular row. Unequal plain lists do not state which row is missing a value.

One quick check

A record is missing one field. What can pd.DataFrame(rows) do?

What you should be able to explain. I can build a DataFrame from records and identify a missing field.

M04C03 · Explore · predict · practice

Look at the beginning and the end

The setup provides students(), a helper that returns a fresh copy of the 12-row fictional practice table. head(n) shows the first n rows and tail(n) shows the last n rows. These previews help you understand a file without printing the whole dataset. A preview alone does not prove every row is valid.

Read the example

df = students()
first = df.head(3)
last = df.tail(2)
print("First three rows:")
print(first)
print("Last two rows:")
print(last)

M04C04 · Explore · predict · practice

Inspect names, types, and a first summary

Attributes such as shape and columns are stored information, so they do not use parentheses. Methods such as info() perform an action and do use parentheses. info() reports column names, non-missing counts, and dtypes; describe() returns summary statistics. Text dtype labels can differ across pandas versions, so focus on what the data represent.

Read the example

df = students()
print("Columns:", df.columns.tolist())
print("Shape:", df.shape)
df.info()
summary = df[["Age", "Score"]].describe()
print(summary.round(2))
