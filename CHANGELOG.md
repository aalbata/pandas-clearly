# Changelog

## 1.0.0 — 2026-10-22

Initial course distribution for publication as `aalbata/pandas-clearly`.

- Added 30 modules containing 120 guided lessons, beginning with a Python bridge and dictionaries.
- Included a question, prediction, explanation, change task, hint, worked solution, and quick check with each lesson.
- Added student and solution notebook collections and independent assessment materials.
- Included a browser classroom with a bundled Python runtime for executing lesson code.
- Added six interactive visual walkthroughs for dictionaries, selection, filtering, grouping, merging, and reshaping.
- Added CSV, delimited-text, Excel, JSON, and public-data exercises with source and provenance notes.
- Included source validation, a reproducible build process, teaching notes, accessibility notes, citation metadata, and GitHub Pages instructions.

The release date identifies this distribution. Publication of a repository or Pages site is a separate action by the maintainer.
